# Contributing

Thank you for contributing to GreenStreet.

## Development Workflow

Fork repository

Create branch

```bash
git checkout -b feature/add-tree-search
```

Commit

```bash
git commit -m "Add tree search feature"
```

Push

```bash
git push origin feature/add-tree-search
```

Create Pull Request

---

## Coding Standards

Backend

- Python
- PEP8

Frontend

- Astro
- TypeScript preferred

Database

- PostgreSQL

---

## Commit Message Examples

```text
feat: add tree adoption endpoint

fix: correct leaflet marker popup

docs: update architecture document

refactor: simplify tree service
```
